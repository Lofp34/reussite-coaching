# Réussite Coaching

## Description
Application web de coaching personnalisé utilisant l'intelligence artificielle pour fournir des retours et analyses pertinents aux utilisateurs.

## Fonctionnalités
- Interface utilisateur intuitive et responsive
- Intégration avec l'API OpenAI pour l'analyse des découvertes
- Système de coaching personnalisé
- Visualisation des progrès

## Technologies Utilisées
- HTML5/CSS3
- JavaScript
- API OpenAI GPT-4
- Bootstrap pour le design responsive

## Installation
1. Clonez le repository :
```bash
git clone https://github.com/Lofp34/reussite-coaching.git
```
2. Ouvrez `index.html` dans votre navigateur

## Configuration de l'API OpenAI
L'application utilise l'API OpenAI pour l'analyse des découvertes. Pour le développement, la clé API est temporairement incluse dans le code HTML. Dans un environnement de production, elle devra être déplacée vers un fichier `.env`.
